# arbox-agent-skills

Community agent skills that help owners of businesses running on [Arbox](https://www.arboxapp.com) (gyms, Pilates, yoga, CrossFit, studios, clinics) use AI coding agents such as Claude Code with their Arbox account. Discover what you can build, then build it safely against the Arbox API.

> **Status: design phase.** No skills ship yet. Research and design notes live in [`docs/`](docs/).
>
> Community project, not affiliated with or endorsed by Arbox.

## Planned

- `arbox-guide`: interviews the owner about their business and suggests what to build
- `arbox-api`: safe access to the [Arbox public API](https://arboxserver.arboxapp.com/docs/api). Reads run freely; writes need confirmation.
- `arbox-recipes`: tested recipes (churn risk, weekly digest, class fill, revenue snapshot...)

Install (planned): Claude Code plugin marketplace, or `npx skills add` for other agents.
