# Launch kit

Ready-to-post copy and images for sharing Arbox Agent Skills. Every claim here matches the README and [evals/results.md](../../evals/results.md); keep it that way when you edit. Images and how to regenerate them: [ASSETS.md](ASSETS.md).

Ground rules for any post:
- Say "community project, not affiliated with Arbox".
- Say what it does today: reads, reports, drafts, and seven small changes (a lead, a lead status or note, a task, a member note), each only after the owner says yes. It never sends messages, books, charges or changes memberships.
- Status is **release candidate**; live verification on a test gym is in progress.
- Link: https://github.com/romiluz13/arbox-agent-skills

## Facebook / LinkedIn post (English)

> If your studio runs on Arbox and you've started playing with Claude Code, I made something for you.
>
> **Arbox Agent Skills** is a free, open-source add-on that teaches Claude Code your business and your Arbox. Ask it things like:
> - "Who used to come every week and went quiet?"
> - "Whose pack runs out in the next two weeks?"
> - "Who owes me money, and whose card failed?"
> - "Give me my week on one page."
>
> You get a short answer, a page you can print, and message drafts you send yourself.
>
> What it won't do: it never sends messages, books classes, charges cards or changes memberships. Your API key is typed once, hidden, and never goes into the chat.
>
> To start, paste this into Claude Code: "Install the Arbox skills from https://github.com/romiluz13/arbox-agent-skills and then help me get started."
>
> It's a release candidate. Try it with the built-in sample studio first, no connection needed. Community project, not affiliated with Arbox.
> https://github.com/romiluz13/arbox-agent-skills

## Demo script (60 seconds, screen recording)

1. In Claude Code: *"What can I build with Arbox?"* → show the three questions with guesses; answer "yes".
2. *"Show me my Monday page with sample data"* → open the page; point at the SAMPLE DATA banner and the "this week" line.
3. *"Send a WhatsApp to everyone who hasn't come this month"* → show the kind refusal and the ready list and draft.
4. End card: the install line.
